1 · Simplifying Radicals

Key ideas
  • Pull out perfect-square factors: \(\sqrt{ab}=\sqrt a\,\sqrt b\).
  • For variables, divide the exponent by 2. The quotient comes out and the remainder stays in.
  • \(\sqrt{-1} = i\), so \(\sqrt{-a} = i\sqrt a\) for \(a>0\).
Assume all variables are nonnegative.
  1. 1. Simplify \(\sqrt{72}\).
  2. 2. Simplify \(\sqrt{50x^3y^4}\).
  3. 3. Simplify \(\sqrt{-49}\) and \(\sqrt{-20}\).

2 · Dividing Radicals & Rationalizing

Key ideas
  • Divide: \(\dfrac{\sqrt a}{\sqrt b}=\sqrt{\dfrac ab}\). Simplify the fraction under the radical first.
  • Rationalize: no radicals in the denominator. Multiply the top and bottom by the radical in the denominator.
  1. 4. Rationalize \(\dfrac{6}{\sqrt3}\).
  2. 5. Simplify \(\dfrac{\sqrt{18x^5}}{\sqrt{2x}}\).

3 · Solving Radical Equations

Steps
  • Isolate the radical.
  • Square both sides.
  • Solve, then check every answer in the original equation. Squaring can create extraneous solutions.
  • If an isolated square root equals a negative number, there is no solution.
  1. 6. Solve \(\sqrt{x+5} = 4\).
  2. 7. Solve \(\sqrt{2x-3} + 2 = 7\).
  3. 8. Solve \(\sqrt{x+7} = x - 5\).
  4. 9. Solve \(\sqrt{x+3} + 5 = 2\).

4 · Solving Quadratic Equations

Methods
  • Factoring: set equal to 0, factor, and use the zero product property.
  • Square roots: isolate the squared part, then take \(\pm\sqrt{\ }\).
  • Completing the square: for \(x^2+bx\), add \(\left(\tfrac b2\right)^2\) to both sides.
  1. 10. Solve by factoring: \(x^2 - 5x - 24 = 0\).
  2. 11. Solve by factoring: \(2x^2 + 7x + 3 = 0\).
  3. 12. Solve using square roots: \(3(x-2)^2 = 48\).
  4. 13. Solve: \(x^2 + 25 = 0\).
  5. 14. Solve by completing the square: \(x^2 + 6x - 7 = 0\).
  6. 15. Solve by completing the square: \(x^2 - 4x - 1 = 0\).
  7. 16. Write \(y = x^2 + 8x + 10\) in vertex form and name the vertex.

5 · Complex Numbers

Key ideas: \(i = \sqrt{-1}\), \(i^2 = -1\), \(i^3 = -i\), \(i^4 = 1\). The powers repeat every 4. Remember \(i^2=-1\) when you multiply.
  1. 17. Simplify \((3 + 2i) + (5 - 7i)\).
  2. 18. Multiply \((2 - 3i)(4 + i)\).
  3. 19. Simplify \(i^{23}\).

6 · Applications

  1. 20. A ball is thrown from a 48-ft platform. Its height is \(h = -16t^2 + 32t + 48\), where \(t\) is in seconds. (a) When does it hit the ground? (b) What is its maximum height?
  2. 21. The distance \(d\) (miles) you can see to the horizon from a height of \(h\) feet is \(d = \sqrt{1.5h}\). How high must you be to see 6 miles?

1 · Simplifying Radicals

Key ideas
  • Pull out perfect squares (for \(\sqrt{\ }\)) or perfect cubes (for \(\sqrt[3]{\ }\)): \(\sqrt{ab}=\sqrt a\,\sqrt b\).
  • For variables, divide the exponent by the index. The quotient comes out and the remainder stays in.
  • \(\sqrt{-1} = i\), so \(\sqrt{-a} = i\sqrt a\) for \(a>0\).
Assume all variables are nonnegative.
  1. 1. Simplify \(\sqrt{72}\).
    Show answer
    \(\sqrt{36\cdot 2} = \) \(6\sqrt2\)
  2. 2. Simplify \(\sqrt{50x^3y^4}\).
    Show answer
    \(\sqrt{25\cdot 2\cdot x^2\cdot x\cdot y^4} = \) \(5xy^2\sqrt{2x}\)
  3. 3. Simplify \(\sqrt[3]{54}\).
    Show answer
    \(\sqrt[3]{27\cdot 2} = \) \(3\sqrt[3]{2}\)
  4. 4. Simplify \(\sqrt[3]{-16a^5b^6}\).
    Show answer
    \(\sqrt[3]{(-8)\cdot 2\cdot a^3\cdot a^2\cdot b^6} = \) \(-2ab^2\sqrt[3]{2a^2}\)
    A cube root of a negative number is real and negative.
  5. 5. Simplify \(\sqrt{-49}\) and \(\sqrt{-20}\).
    Show answer
    \(7i\) and \(\sqrt{-1}\cdot\sqrt{4\cdot5} = \) \(2i\sqrt5\)

2 · Operations with Radicals

Key ideas
  • Add or subtract only like radicals (same index and same radicand). Simplify first.
  • Multiply: \(\sqrt a\cdot\sqrt b=\sqrt{ab}\). Use FOIL for binomials.
  • Rationalize: no radicals in the denominator. For a binomial denominator, multiply by the conjugate.
  1. 6. Simplify \(3\sqrt{12} + 5\sqrt{27} - \sqrt{48}\).
    Show answer
    \(3(2\sqrt3) + 5(3\sqrt3) - 4\sqrt3 = 6\sqrt3 + 15\sqrt3 - 4\sqrt3 = \) \(17\sqrt3\)
  2. 7. Simplify \(\sqrt6\cdot\sqrt{15}\).
    Show answer
    \(\sqrt{90} = \sqrt{9\cdot10} = \) \(3\sqrt{10}\)
  3. 8. Multiply \((2+\sqrt3)(4-\sqrt3)\).
    Show answer
    \(8 - 2\sqrt3 + 4\sqrt3 - 3 = \) \(5 + 2\sqrt3\)
  4. 9. Expand \((\sqrt5 - 2)^2\).
    Show answer
    \((\sqrt5)^2 - 2(2)\sqrt5 + 4 = 5 - 4\sqrt5 + 4 = \) \(9 - 4\sqrt5\)
    Common error: \((\sqrt5-2)^2 \ne 5 + 4\). Don't forget the middle term.
  5. 10. Rationalize \(\dfrac{6}{\sqrt3}\).
    Show answer
    \(\dfrac{6}{\sqrt3}\cdot\dfrac{\sqrt3}{\sqrt3} = \dfrac{6\sqrt3}{3} = \) \(2\sqrt3\)
  6. 11. Rationalize \(\dfrac{5}{3-\sqrt2}\).
    Show answer
    Multiply by the conjugate \(\dfrac{3+\sqrt2}{3+\sqrt2}\): \(\dfrac{5(3+\sqrt2)}{9-2} = \) \(\dfrac{15+5\sqrt2}{7}\)
  7. 12. Simplify \(\dfrac{\sqrt{18x^5}}{\sqrt{2x}}\).
    Show answer
    \(\sqrt{\dfrac{18x^5}{2x}} = \sqrt{9x^4} = \) \(3x^2\)

3 · Rational Exponents

Key idea: \(a^{m/n} = \left(\sqrt[n]{a}\right)^m = \sqrt[n]{a^m}\), and \(a^{-k} = \dfrac{1}{a^k}\). The denominator is the root (“power over root”).
  1. 13. Evaluate \(27^{2/3}\).
    Show answer
    \(\left(\sqrt[3]{27}\right)^2 = 3^2 = \) \(9\)
  2. 14. Evaluate \(16^{-3/4}\).
    Show answer
    \(\dfrac{1}{16^{3/4}} = \dfrac{1}{\left(\sqrt[4]{16}\right)^3} = \dfrac{1}{2^3} = \) \(\dfrac18\)
  3. 15. (a) Write \(\sqrt[4]{x^3}\) in exponent form. (b) Write \(y^{2/5}\) in radical form.
    Show answer
    (a) \(x^{3/4}\)   (b) \(\sqrt[5]{y^2}\)

4 · Solving Radical Equations

Steps
  • Isolate the radical.
  • Raise both sides to the index power (square for \(\sqrt{\ }\), cube for \(\sqrt[3]{\ }\)).
  • Solve, then check every answer in the original equation. Squaring can create extraneous solutions.
  • If an isolated square root equals a negative number, there is no solution.
  1. 16. Solve \(\sqrt{x+5} = 4\).
    Show answer
    \(x+5 = 16 \Rightarrow\) \(x = 11\). Check: \(\sqrt{16}=4\) ✓
  2. 17. Solve \(\sqrt{2x-3} + 2 = 7\).
    Show answer
    \(\sqrt{2x-3} = 5 \Rightarrow 2x-3 = 25 \Rightarrow\) \(x = 14\). Check: \(\sqrt{25}+2 = 7\) ✓
  3. 18. Solve \(\sqrt{x+7} = x - 5\).
    Show answer
    \(x+7 = x^2 - 10x + 25 \Rightarrow x^2 - 11x + 18 = 0 \Rightarrow (x-9)(x-2) = 0\)
    Check \(x=9\): \(\sqrt{16} = 4 = 9-5\) ✓
    Check \(x=2\): \(\sqrt9 = 3 \ne 2-5 = -3\) ✗ (extraneous)
    \(x = 9\)
  4. 19. Solve \(\sqrt[3]{x-4} = -3\).
    Show answer
    Cube both sides: \(x - 4 = -27 \Rightarrow\) \(x = -23\)
  5. 20. Solve \(\sqrt{x+3} + 5 = 2\).
    Show answer
    \(\sqrt{x+3} = -3\). A principal square root can't be negative, so there is no solution.
    If you square anyway, you get \(x = 6\), but it fails the check: \(\sqrt9 + 5 = 8 \ne 2\).

5 · Solving Quadratic Equations

Methods
  • Factoring: set equal to 0, factor, and use the zero product property.
  • Square roots: isolate the squared part, then take \(\pm\sqrt{\ }\).
  • Completing the square: for \(x^2+bx\), add \(\left(\tfrac b2\right)^2\) to both sides.
  1. 21. Solve by factoring: \(x^2 - 5x - 24 = 0\).
    Show answer
    \((x-8)(x+3) = 0 \Rightarrow\) \(x = 8,\ x = -3\)
  2. 22. Solve by factoring: \(2x^2 + 7x + 3 = 0\).
    Show answer
    \((2x+1)(x+3) = 0 \Rightarrow\) \(x = -\tfrac12,\ x = -3\)
  3. 23. Solve using square roots: \(3(x-2)^2 = 48\).
    Show answer
    \((x-2)^2 = 16 \Rightarrow x - 2 = \pm 4 \Rightarrow\) \(x = 6,\ x = -2\)
  4. 24. Solve: \(x^2 + 25 = 0\).
    Show answer
    \(x^2 = -25 \Rightarrow x = \pm\sqrt{-25} = \) \(\pm 5i\)
  5. 25. Solve by completing the square: \(x^2 + 6x - 7 = 0\).
    Show answer
    \(x^2 + 6x = 7 \Rightarrow x^2 + 6x + 9 = 16 \Rightarrow (x+3)^2 = 16\)
    \(x + 3 = \pm4 \Rightarrow\) \(x = 1,\ x = -7\)
  6. 26. Solve by completing the square: \(x^2 - 4x - 1 = 0\).
    Show answer
    \(x^2 - 4x + 4 = 1 + 4 \Rightarrow (x-2)^2 = 5 \Rightarrow\) \(x = 2 \pm \sqrt5\)
  7. 27. Write \(y = x^2 + 8x + 10\) in vertex form and name the vertex.
    Show answer
    \(y = (x^2 + 8x + 16) + 10 - 16 = \) \((x+4)^2 - 6\), vertex \((-4,\,-6)\)

6 · Complex Numbers

Key ideas: \(i = \sqrt{-1}\), \(i^2 = -1\), \(i^3 = -i\), \(i^4 = 1\). The powers repeat every 4. Always rewrite \(\sqrt{-a}\) as \(i\sqrt a\) before multiplying.
  1. 28. Simplify \((3 + 2i) + (5 - 7i)\).
    Show answer
    \(8 - 5i\)
  2. 29. Multiply \((2 - 3i)(4 + i)\).
    Show answer
    \(8 + 2i - 12i - 3i^2 = 8 - 10i + 3 = \) \(11 - 10i\)
  3. 30. Simplify \(i^{23}\).
    Show answer
    \(23 \div 4\) has remainder 3, so \(i^{23} = i^3 = \) \(-i\)
  4. 31. Simplify \(\sqrt{-8}\cdot\sqrt{-2}\).
    Show answer
    \((2i\sqrt2)(i\sqrt2) = 2i^2\cdot 2 = \) \(-4\)
    Trap: \(\sqrt{-8}\cdot\sqrt{-2} \ne \sqrt{16} = 4\). Pull out the \(i\) first.

7 · Applications

  1. 32. A ball is thrown from a 48-ft platform. Its height is \(h = -16t^2 + 32t + 48\), where \(t\) is in seconds. (a) When does it hit the ground? (b) What is its maximum height?
    Show answer
    (a) \(-16(t^2 - 2t - 3) = 0 \Rightarrow -16(t-3)(t+1) = 0\). Time can't be negative, so \(t = 3\) seconds.
    (b) The vertex is at \(t = -\dfrac{b}{2a} = -\dfrac{32}{-32} = 1\), and \(h(1) = -16 + 32 + 48 = \) 64 ft.
  2. 33. The distance \(d\) (miles) you can see to the horizon from a height of \(h\) feet is \(d = \sqrt{1.5h}\). How high must you be to see 6 miles?
    Show answer
    \(6 = \sqrt{1.5h} \Rightarrow 36 = 1.5h \Rightarrow\) \(h = 24\) ft

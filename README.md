# Algebra 2B · Unit 2 Quiz 2 Review: Radicals & Quadratics

An interactive review page (`index.html`) with 37 practice problems and worked answers you can show or hide.

| Section | Topics | Problems |
|---|---|---|
| 1 | Simplifying radicals (square/cube roots, variables, √ of negatives) | 1–5 |
| 2 | Adding, multiplying, and rationalizing radicals (conjugates) | 6–12 |
| 3 | Rational exponents | 13–15 |
| 4 | Solving radical equations and extraneous solutions | 16–20 |
| 5 | Solving quadratics: factoring, square roots, completing the square, quadratic formula, discriminant, vertex form | 21–31 |
| 6 | Complex numbers | 32–35 |
| 7 | Applications | 36–37 |

## Using it
- Open `index.html` in any browser, or turn on **GitHub Pages** (Settings → Pages → Deploy from branch → root) to get a link you can share with students.
- **Show all / Hide all** buttons toggle every answer at once.
- **Print (questions only)** prints a blank worksheet. **Print (with answer key)** prints every worked solution.
